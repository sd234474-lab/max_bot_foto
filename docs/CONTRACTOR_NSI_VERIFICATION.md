## Реализовано

Миграции 0048–0050, отдельные справочники НСИ с FK и постоянными ID,
авторизованный API и страницы React, журнал изменений и проверка версии
при сохранении, неизменяемость подтверждённой договорной редакции,
датированное утверждение операционного владельца, раздельные связи
Wialon/MAX, чтение оригиналов с проверкой SHA-256, первоначальный импорт
с индивидуальными замечаниями и без перезаписи существующих карточек.

Юридический профиль связан с существующим Organization.id. Нового
конкурирующего справочника наших организаций не создаётся.

сопоставление с конкретной договорной территорией не угадывается.

## Оставлено на проверке

- Две строки Халилова с неоднозначными/латинскими госномерами не создали
  карточек. Остальные строки обработаны.
- У десяти машин нет утверждённого рабочего имени: созданы временные
  подписи и состояние «Требует заполнения».
- Два банковских счёта Халилова, сохранённые Excel как числа, не приняты
  как точные строки. Два БИК требуют проверки девятизначного представления.
- Юридические собственники, достоверность сканов, тарировки и тип BOBCAT
  требуют сверки. Документы до сверки связаны с контрагентом.
- Две машины Шашко имеют только кандидатное указание ответственного;
  юридические реквизиты Шашко не выдуманы.
